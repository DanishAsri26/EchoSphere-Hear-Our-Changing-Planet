# Instrument sample credits
All instruments are recorded samples, re-pitched in the browser by Tone.js `Sampler`. Only the notes listed in each folder are included.

**Line-up rule (15 Nov):** within one song, no two data layers use the same instrument family.
Orchestra: Fire = Trumpet (brass) · Rain = Harp (strings) · CO₂ = Bassoon (woodwind) · Sea level = Cello (strings; never in the same song as Harp) · accent = Timpani.
Modern Band: Fire = Saxophone (woodwind) · Rain = Electric piano (keyboard) · CO₂ = Electric bass (guitar) · Sea level = Synth pad (synth).
